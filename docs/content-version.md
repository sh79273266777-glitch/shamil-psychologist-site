# Версия содержания

- Версия сайта: 1.0.0.
- Редакция публичных юридических документов: 1.0.
- Дата создания и редакции: 13.09.2026.
- Источник правил: техническое задание владельца от 13.09.2026.
- Публичные документы: терапевтический контракт, условия оказания психологических консультационных услуг, политика обработки персональных данных.
- Политика ПДн является незавершённой структурой. Данные оператора не определены. Условия услуг также требуют добавления статуса и реквизитов исполнителя до юридического запуска.
- Контакты не предоставлены. Недоступные кнопки не являются работающими каналами связи.
- Два документа в legal/drafts/ — недействующие черновики для будущего отдельного подписания; ссылок на них в основной навигации нет. При технической публикации файлы доступны по прямым адресам.

При изменении существенных условий повысить редакцию и изменить дату в каждом затронутом юридическом документе, согласовать текст главной страницы, обновить footer и настоящий файл, добавить запись в legal-change-log.md. Коммит сохраняет предыдущую редакцию; дата страницы должна обозначать дату изменения текста, а не дату загрузки посетителем.

Перед использованием сайта для принятия условий оплатой заполнить и утвердить обязательные юридические сведения. Техническая публикация сама по себе этого не заменяет.
