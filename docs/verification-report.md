## Производительность и ограничения проверки

В одном дополнительном замере с отключённым кэшем, задержкой сети 150 мс, скоростью загрузки 200 000 байт/с и четырёхкратным замедлением CPU: FCP 512 мс, LCP 512 мс, событие load около 493 мс. Это лабораторное наблюдение, а не гарантия скорости для каждого посетителя.

Lighthouse не установлен и не запускался. Баллы Performance, Accessibility и Best Practices >=95 не подтверждены. Проверка контраста, семантики и клавиатуры не заменяет полный аудит WCAG и проверку человеком со скринридером. Размеры экранов проверены в эмуляции браузера, а не на шести физических устройствах. Встроенная в абзац ссылка на политику имеет стандартную высоту строки; это текстовая ссылка, а не отдельная кнопка.

При отправке HTML в валидатор без адреса сайта возникало предупреждение о разрешении относительного пути CSS в CSP. Повторная проверка всех страниц по реальным опубликованным URL вернула пустые списки замечаний. Ослабление CSP не потребовалось.
